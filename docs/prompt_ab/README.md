# Prompt A/B scorecards

Generated by `tradingagents/evaluation/prompt_ab.py::run_prompt_ab()`
(workstream A6 in `docs/PROMPT_AND_CORE_FEATURES_PLAN.md`).

Each file here is the evidence for one prompt-version comparison: hit-rate,
PnL, calibration, consistency, and cost deltas between a baseline and
candidate `prompt_versions` configuration, plus report-quality judge scores
when a judge LLM was supplied.

## Convention

A PR that bumps a prompt's default version in `default_config.py`'s
`prompt_versions` should include the scorecard that justified the bump,
committed here. Flip the default only when the candidate is non-inferior
on hit-rate/calibration and superior on judge scores — a regression on any
metric should be explained in the PR description, not silently merged.

## Generating one

```bash
python -m tradingagents.evaluation.prompt_ab \
    --baseline '{"researchers/bull_researcher": "v1"}' \
    --candidate '{"researchers/bull_researcher": "v2"}' \
    --tickers AAPL MSFT --dates 2025-06-30 \
    --label bull-researcher-v2
```

Requires the same API keys/config `tradingagents.evaluation.benchmark`
needs — it runs the real multi-agent pipeline against both configurations,
so it is not free and not something CI runs automatically.
